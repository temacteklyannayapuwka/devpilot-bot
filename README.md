# DevPilot Bot

Личный Telegram-бот для просмотра лимитов Codex на Mac. Работает через long polling без публичного входящего порта. Доступ разрешён только владельцу в личном чате.

## Возможности

- `/start` — открыть панель лимитов с периодическим обновлением одного сообщения.
- `/limits` — получить свежие лимиты и перенести автоматическое обновление в новое сообщение.
- `/status` — проверить состояние бота.
- `/stop` — остановить обновление панели.
- `/models` — получить доступные модели из Codex CLI.
- `/model` — показать сохранённую модель.
- `/model ИМЯ` — выбрать модель из доступного списка.
- `/model default` — вернуть выбор модели по умолчанию Codex.

Выбор сохраняется локально в `.devpilot/settings.json` и переживает перезапуск. Он предназначен для задач DevPilot и не меняет модель в существующих чатах Codex. Выполнение задач разработки пока не подключено. Для выбора модели требуется доступный и авторизованный Codex CLI; сброс в `default` работает без обращения к Codex.

Панель показывает доступные окна лимитов, процент остатка и время сброса. По умолчанию обновляется каждые 5 минут, с возможной задержкой до одного цикла опроса Telegram и запроса Codex. Отсутствующие данные не заменяются оценками. Это лимиты Codex, а не всех функций ChatGPT и не точное число оставшихся сообщений. При перезапуске бота отправь `/start` заново.

## Запуск на macOS

Нужны Python 3.11+, Git и установленный Codex CLI с авторизацией через ChatGPT. Сторонние Python-пакеты не требуются.

```bash
git clone https://github.com/temacteklyannayapuwka/devpilot-bot.git
cd devpilot-bot
codex login
cp .env.example .env
chmod 600 .env
```

Создай бота через `@BotFather`. В `.env` заполни `TELEGRAM_BOT_TOKEN` и числовой `TELEGRAM_OWNER_ID` своего аккаунта. Сохрани кавычки и `export`. Если `codex` отсутствует в PATH, укажи абсолютный путь в `CODEX_BIN`. Не публикуй `.env` и токены.

```bash
source .env
python3 bot.py
```

Открой личный чат с ботом и отправь `/start`. Запускай только один экземпляр. Mac должен быть включён, подключён к интернету и не находиться в режиме сна. Бот должен использовать токен без настроенного webhook. Автозапуск и выполнение задач разработки в текущую версию не входят.
